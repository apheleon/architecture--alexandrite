# Задание 3. Трейсинг

## Данные для трейсинга
1. Каждый входящий в API запрос получит уникальный request-ID
2. Проходя по стеку вызовов бутем писать временные метки
3. Будем писать тип запроса, например: order, calculation, mqin, mqout, etc.
4. Данные пользователя: guid, ip, env, etc.

## Мотивация
1. Клиенты сталкиваются с потеряй заказов
2. Компания не соблюдает сроки по заказам
3. Пользователи сталкиваются с высокой latency

Предлагаемое внедрение трейсинга должно помочь в следующем:
1. Выявить место в котором теряются или зависают заказы, прямо влияет на прибыль компании
2. Выявить места в которых высокая latency
3. Выявить места с низкой пропускной способностью.
